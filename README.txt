ЧАТ-ЧАТ: ОБЩИЙ СЕРВЕР В ИНТЕРНЕТЕ
=================================
Зачем: чтобы вы и папа могли переписываться с разных компьютеров и телефонов.
Сервер работает всегда, а приложения (exe и apk) только открывают его.

Нужно: почта Gmail, аккаунт на github.com, аккаунт на render.com и банковская карта (около 7 долларов в месяц за сервер с диском).

ШАГ 1. Пароль приложения для Gmail (чтобы сервер мог отправлять коды на почту)
1. Откройте myaccount.google.com -> «Безопасность» -> включите «Двухэтапная аутентификация».
2. Откройте myaccount.google.com/apppasswords, назовите пароль «Чат-Чат», нажмите «Создать».
3. Google покажет 16 букв. Скопируйте их БЕЗ пробелов. Никому их не отправляйте, в том числе в чат.

ШАГ 2. Загрузите папку на GitHub
1. На github.com нажмите «+» -> New repository. Имя: chat-chat. Выберите Private. Create.
2. На странице репозитория нажмите «uploading an existing file».
3. Распакуйте этот архив и перетащите в окно ВСЁ его содержимое (файлы и папку public). Нажмите Commit changes.

ШАГ 3. Запустите на Render
1. На render.com войдите через GitHub. Нажмите New -> Blueprint, выберите репозиторий chat-chat.
2. Render спросит два значения:
   SMTP_URL:  smtps://ВАША_ПОЧТА%40gmail.com:ПАРОЛЬ_ПРИЛОЖЕНИЯ@smtp.gmail.com:465
              (вместо @ в почте пишем %40, например anna%40gmail.com)
   MAIL_FROM: Чат-Чат <ВАША_ПОЧТА@gmail.com>
3. Нажмите Apply и подождите 3-5 минут. Появится адрес вида https://chat-chat-xxxx.onrender.com
4. Откройте этот адрес в браузере: должна открыться страница входа. Пришлите адрес Claude, и он соберёт ChatChat.exe для вас и папы.

Тестовый режим на сервере выключен: код приходит на почту.
Данные хранятся на диске сервера (папка /data) и не пропадают при перезапуске.
